# Bundled fonts

Noto Sans Georgian (Light, Regular, SemiBold) and Noto Serif Georgian (Regular, Bold), Georgian + Latin subsets, converted from the `@fontsource` npm packages. Licensed under the SIL Open Font License 1.1.

`scripts/render.py` copies this folder next to the subtitle file so captions render with the brand fonts even when they are not installed on the system.

Not included: **Zodiak** (Verve's Latin header font, from Fontshare) and the lari sign (₾), which these subsets lack. Add `Zodiak-Bold.otf` here if Latin headers are needed.
